# Third-party data

Some questions in this folder come from public benchmarks. They are not covered by the MIT licence in the repository root, and they keep their original licences.

| File | MMLU-Pro | ARC-Challenge |
|---|---|---|
| `arbiter_500.jsonl` | 400 | 100 |
| `followup_500.jsonl` | 400 | 100 |
| `followup_calibration_60.jsonl` | 48 | 12 |

Every benchmark row has `metadata.source` set to `mmlu_pro` or `arc_challenge`, and `source_question_id`, `source_row_index` and `source_revision` point back to the original.

- **MMLU-Pro**, by TIGER-Lab, MIT licence: https://github.com/TIGER-AI-Lab/MMLU-Pro
- **ARC-Challenge** (AI2 Reasoning Challenge), by the Allen Institute for AI, licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/): https://allenai.org/data/arc

**Changes:** the questions were sampled and reformatted into this project's JSONL format (question, choices, correct label and metadata). The ARC-Challenge questions in these files, as adapted, are shared under CC BY-SA 4.0.

All other files in this folder contain questions generated by this project and are covered by the MIT licence in the repository root.
