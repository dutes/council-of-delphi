# Phase 2 Exploratory Archive

This directory is an immutable evidence package for the completed Phase 2 run. It must not be modified or combined with Phase 3 results.

Phase 2 found an exploratory paired improvement from 67.37% Round-one vote accuracy to 74.23% Delphi accuracy on 947 completed runs (89 wrong-to-right, 24 right-to-wrong). However, 553 Delphi runs failed, predominantly because Google prepaid credits were depleted. Missingness was therefore non-random and the result is not confirmatory.

The source snapshot reconstructs the run-time code by removing only the Phase 3 Gemini-thinking option added immediately before this archive was created. The project was not a Git repository during Phase 2, so no original Git commit exists.

Verify every artifact with `SHA256SUMS.txt`.
